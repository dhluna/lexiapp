# Logotipo de Lexi

| Archivo | Uso |
| --- | --- |
| `lexi-logo.svg` / `.png` | Logotipo «lexi.» para fondos claros (tinta `#16193b`, punto `#3a3ed6`). |
| `lexi-logo-dark.svg` / `.png` | Logotipo para fondos oscuros (`#f3f5fb`, punto `#9a9dff`). |
| `lexi-icon.svg`, `lexi-icon-1024.png`, `lexi-icon-512.png` | Símbolo «l.» (fondo `#3a3ed6`, punto `#ffe45c`): avatar, redes, tiendas, Google OAuth. |

- Tipografía: Bricolage Grotesque Bold (licencia OFL), con las letras convertidas en trazados:
  los SVG no necesitan la fuente instalada.
- Deja alrededor del logotipo un margen de, al menos, la altura de la «x».
- No cambies los colores, no lo estires y no lo pongas sobre fondos con poco contraste.
- Los iconos de la web (`apps/web/src/app/icon.svg`) y de la app (`scripts/generate-app-icons.mjs`)
  usan el mismo símbolo.
